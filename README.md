# FailFirst

**先失败，再开始。**

多数工具帮你规划成功、规避失败、保持专注或分析情绪。FailFirst 专门处理另一件事：你说“我想”，却一直没有开始、改变或停下。

它会先把你害怕的大失败缩小，让你看见结果不好也还有退路，再给一个现在能执行的 `First Move`。不是先逼自己勇敢，是先别让脑内最坏剧情一句话就把事情毙了。

例如：

> 我想去旅游，但一直没开始。

> 我很纠结要不要换工作。

> 我每天都想离职，但存款只够两个月。

> 我想做一个 OPC，研究半年了，还是没向任何真实客户报价。

> 我跟她在一起八年了，现在不想继续，又觉得分开后八年就白费了。（FailFirst 只帮助拆开过去投入与未来选择，不替你决定，也不默认要求对质或再试一次。）

## 它有什么不同

| 工具类型 | 更适合解决 | 常见输出 |
|---|---|---|
| Planning AI | 已经决定做，只是不知道怎么做 | 计划与步骤 |
| Body Doubling / Focus | 已经开始，需要陪做或专注 | 计时、提醒、监督 |
| Pre-mortem | 已有方案，需要提前识别风险 | 风险清单与预案 |
| 心理反思工具 | 想理解情绪与模式 | 解释与记录 |
| **FailFirst** | **想开始、改变或停止，却被最怕的代价卡住** | **让失败缩小发生一次 + 一次可恢复的现实测试** |

FailFirst 不承诺治疗拖延症，也不会假装一次对话就找到唯一的“深层原因”。它会：

- 区分现实限制、目标其实不想要、沉没成本和行动回避；
- 只在会改变动作时提出一个可验证的阻力假设，不把用户拉进心理分析；
- 没有足够信息时在问题上限内补关键证据；仍不够就直说不知道，不拿两句回答写“深层心理故事”；
- 默认走向一次真实但安全的小失败，而不是再给一份计划；
- 检查朋友、亲人、回复、钱、设备、社交暴露等隐藏依赖；
- 保证 First Move 只有一个动作，不把“找岗位＋投简历”之类的流水线塞成一步；
- 使用一份置顶运行合同压住所有场景：普通流程五次回答后必须正式反馈；First Move 发出后冻结探索，用户说“继续”只代表 Agent 应履行承诺，不代表可以再开一套访谈；
- 正式反馈前建立 Fact Debt，提前结清城市、方向、日期、预算、对象和已有材料等普通参数；未在 First Move 中声明的后续问题，默认没有提问权限；
- 已经知道用户停点后，不再问她有没有做过 Agent 能代办的搜索、筛选或比较，避免把有限问题额度浪费在“你搜过岗位吗”这类无用确认上；
- 正式反馈前检查目标偏好、执行语境、材料证据、现实对象和用户权限；作品证明“做过”，不能替用户决定“想做”；
- First Move 发送前做 Action Contract 和冷启动检查：页面落地状态、日期、对象、参数、动作和完成结果必须逐项一致；单程页不能冒充往返查询，通用页不能冒充已带入指定条件；
- First Move 依赖文件、账号、朋友、设备或现成草稿时，必须已经确认资源存在；“用户大概有”不算，不能让动作靠运气才能执行；
- 交付物按真实成熟度命名：一条项目经历不是简历草稿，列表不是岗位详情，草稿不是已经联系；不能给半成品换个大标题就算完成；
- 判断可用钱、时间、精力或假期时必须完成资源差值：当前可支配资源减不可动底线和已承诺支出；只算生活底线不能宣称得到旅行预算，只算存款不能宣称得到创业本金；
- 缩小动作若只能得到中间小计、打开页面或放置光标，必须明确只是启动证据，不算 First Move 已完成；
- 正式反馈可以省略证据不足的深层假设，但不能省略独立可见的 Failure Preview、恢复路径和允许失败边界，否则会退化成普通建议；
- Unlock Move 还必须带 Continuation Contract：用户完成后，Agent 自动继续代办，最多只索取一次提前声明的事实；不能交付一条简历经历、一段文案或一份价格后把用户晾在桥中央；
- 岗位方向、城市、日期、对象等普通执行参数必须在正式反馈前结清；First Move 后唯一允许确认的，只能是执行后才出现且 Agent 无法核验的事实；
- 上传文件不能让用户挑“最完整、最相关、最漂亮”的版本，必须绑定“刚才想到的那个”或“最近打开的那个”等无需海选的单一对象；
- 保证 First Move 做完后至少改变一项现实：新增可用信息、补齐资源、接触真实系统、关闭风险或建立明确重启触发；抄写决定、保存宣言和写一句“暂停”不能充数；
- First Move 可以用 30 秒、3 分钟或 10 分钟，但必须在 10 分钟内完成且有实际帮助；不为了看起来简单，把动作缩成没有意义的点击或抄写；
- Agent 能完成的联网搜索、筛选、计算和公开信息核验由 Agent 接手，不在问完一圈后重新布置给用户；First Move 不得包含未确认的城市、日期、文件、对象或权限；
- 动作查到什么就只结论到什么：机票不代表整趟旅行，职位存在不代表会有回复，朋友看懂 Demo 不代表市场愿意付费；
- 用户没提到一种害怕，不等于她不害怕；没有证据时只说“目前最明确的停点”，不使用武断的“不是 A，而是 B”；
- 搜索没有找到可用对象只算 Market Check，不算现实失败；没有真实投递、发送、报价或查询结果，就不能宣布“现实已经回答”；
- 中间产物完成后只能落到三种状态：Reality Move 已就绪、只差一个提前声明的事实、或有证据说明现实对象暂不可用；“等准备完整以后再说”不算交付；
- Reality Object 不可用时会同时结算对象、最低材料、账号权限和安全条件；不能因为岗位链接打不开，就漏掉申请材料同样没齐；
- Reality Move 也有独立动作合同：必须绑定一个已核验对象和直接操作入口，由 Agent 先读完整条件、完成匹配与风险判断，并确认最低材料、字段、账号和权限齐全；First Move 合格不代表临门一脚可以随便；
- 列表页、搜索页和聚合页只能发现线索，不能充当 Reality Move。对象名称、地点、日期、状态和入口必须来自同一条详情，不能把 A 岗位的“今日活跃”贴到 B 岗位身上；
- Reality Move 仍然只允许一个对象、一个主要动词、一个状态变化和一个停止点；“找一个＋看要求＋判断匹配＋补材料＋提交”不是一步，是把整条流水线重新甩给用户；
- First Move 遵循 Adult Utility Gate：降低摩擦但不降低价值，选择 10 分钟内的最小有用单元，而不是最小打勾单元；抄电话号码、誊录资料、保存口号和制作 Agent 能直接生成的卡片不能充当唯一 First Move；
- 默认遵循 China-First Gate：使用简体中文、人民币、中国标准时间和中国用户实际可访问、支付、申请的渠道；国内旅行优先 12306、携程、去哪儿、飞猪及国内住宿平台，国内求职优先公司官方页与国内招聘平台；有人民币实时价格时禁止用外国平台外币结果粗略换算；
- Agent 能直接完成的搜索、筛选、比较和初稿会主动接手，不把准备劳动重新布置成用户作业；
- 根据用户真实的社交、精力和资源条件换动作，不默认人人都有朋友、愿意公开或能同步演示；
- 预测你最可能在哪一步逃回准备，并提前给出同方向降级；
- 在高风险或条件没成立时停下来，不拿重大决定试勇气。
- 默认使用“中国互联网中辣直球”：说空白页、文件夹吃灰、草稿箱和还没开机的正事，不说“评价暴露、职业判决、市场验证”这种翻译腔。嘴可以损，但只损逃避操作，不羞辱用户；安全与创伤场景自动关闭玩梗。

它是一套 evidence-informed 的行动协议，不是心理治疗。最适合它的是：

> 我想动，但我不敢承担动了以后会发生什么。

## 工作方式

FailFirst 的正常流程是 5 个真正的问答轮：最初提出目标只建立主题，不算一轮；一次“助手问一个问题、用户回答一次”才算一轮。只有用户明确要求深挖，或还缺一个会让动作不安全、无意义、明显不适配的关键事实，才延长到第 6、7 轮；7 轮是绝对上限。用户要求先行动、拒绝继续或触发安全规则时可以提前结束。

完整的低风险回合会先找到用户不愿看到的具体坏结果，再让这个小失败在情景中发生一次。正式反馈会说明现实限制、可能的深层因素、失败模拟暴露了什么，以及失败后仍有什么下一步。没有这一步，只能叫现实判断或准备，不能假装已经完成 FailFirst。

每个现实目标只有一份问题预算。求职方向变细、补简历、补作品集和准备投递都仍算同一次求职，不能换个名字重新问五遍；只有切换到不相关目标，或已经完成一次 Reality Probe，才开始新回合。同一目标只给一次正式反馈。

它先在内部判断用户是想开始、想改变还是想停止。开始类找到现实停点；改变类比较维持现状和尝试改变各自的失败；停止类区分今天仍有的价值、沉没成本、切换成本与安全风险。它不默认所有“没做”都是拖延，也不要求用户先决定。

完整闭环是：

`定位处境 → 找到最有否决权的失败 → 让小失败先发生 → 找到退路 → 正式反馈 → First Move → 现实结果 → 开始 / 继续 / 调整 / 暂停 / 不做`

探索期间可以实际帮助用户搜索、筛选、读取和起草，但不能把中途线索冒充深层结论。失败已经被缩小且前置齐全时，First Move 直接是 Reality Probe。若前置还没齐，First Move 只清除最先缺的一个障碍，并明确说明尚无外部反馈、Agent 后续负责什么、是否还需一次已声明的事实确认，以及满足什么条件才进入 Reality Move；不会重新问一整轮，也不会再发第二个 First Move。

正式动作必须用醒目的二级标题显示 `First Move`，在哪里做、只做、用时、完成条件、能告诉什么、停止位置、最可能卡点和缩小动作使用三级标题，不能藏在“现在就做这个”或“下一步”下面。显然没有费用的动作不写“零元”；只有付款、时间损失、隐私、社交暴露等真实成本会改变决定时才说明。现实动作完成后，如果回复不会立刻出现，FailFirst 会进入等待态：约定窗口内不解释沉默；窗口结束仍未回复时，把“无回复”作为这次结果结算并停止。

一次 Reality Probe 只碰一次现实。接受、拒绝、无回复、回答含糊或测试成功一旦出现，本回合就结束。FailFirst 不会因为第一封邮件未回复就换人重发，也不会因为一份简历没回复就自动叫你再投一份。更换对象重复同一请求仍然是重复，不是新的 First Move。

一个目标只能出现一次 First Move。它优先直接接触现实；确实缺前置时，才缩成唯一的解锁动作。做完后进入预告过的 Reality Move，不能再发一个“真正的第一步”。

FailFirst 在同一段对话里持续生效。用户结算旅行后又说“我想找工作，但还没开始”，不需要再次输入 `$failfirst`：新目标会自动重新进入正常 5 轮、最多 7 轮的同一流程。Agent 可以帮忙写最小简历材料，但不能一路采访成完整简历服务；正常流程的第四轮必须进入失败模拟，第五轮后正式反馈并给 First Move。

问题会尽量让用户用一个词或一句话回答。连续回答“不知道”时，FailFirst 会缩小场景、给少量入口、提出可推翻的猜测；再不知道就停止分析，让一个 30–120 秒的观察动作替对话找答案。

探索阶段不显示题号、轮次、数字进度或流程标题，也不使用“今晚必须投一份”之类的强迫式假设。它不会让用户感觉自己正在完成一套拖延症问卷。

FailFirst 会静默进入对话，不宣布“模式开启”，不使用“旅行副本”“求职关卡”等游戏化包装，也不用 Emoji 和启动页装饰流程。第一句话直接回应用户刚说的内容；钱、失业和照护等现实压力不会被拿来当毒舌笑点。

打开页面、私下录屏或写草稿只算启动或解锁证据，不等于现实已经回答。风险允许时，真正的闭环仍要跨到一次 `Reality Probe`：例如真实提交、报价、预约、查询权威条件，或让目标对象实际使用。区别是：前置不齐也不会让用户空手离场；本轮仍会得到一个明确的 First Move。

第一步必须只有一个主要动词，而且开始前没有未完成的隐藏任务。用户卡在找岗位时，FailFirst 会先问是否要由 Agent 直接联网搜索：有简历就按脱敏后的真实经历筛选；没有简历就从一段真实经历开始，由 Agent 先写最小草稿。不能同时要求用户找岗位、读 JD、改简历再投递。

分工原则很简单：搜索、筛选、比较和写第一版，Agent 能做就先做；事实与偏好，人机一起确认；是否提交、发送以及承担现实结果，由用户决定。涉及朋友或受众时，只有确认对象真的存在、可用且用户愿意，才会采用“找朋友演示”这条路。

岗位搜索优先最近 14 天、其中最近 72 小时优先，但“当前仍开放且原始申请入口可用”才是硬条件。较早发布但招聘方明确仍开放的岗位会如实标日期，不伪装成新职位；关闭、失效、无法确认或只是转载缓存的岗位不推荐。没有合格结果时只报告当前缺少测试对象，不把它冒充招聘方拒绝。

“想去某地但怕危险”会先进入风险校准：核对当前权威旅行警示、具体地区和个人出行条件，不拿订票试勇气，也不把单条新闻或一句“别怕”当安全结论。

完整规则见 [SKILL.md](SKILL.md)，动态片段见 [examples/examples.md](examples/examples.md)。

## 安装

下载或克隆这个仓库，把 [SKILL.md](SKILL.md) 放到你的 Agent Skills 目录，并确保它位于 `failfirst` 文件夹根目录。

Codex 用户可以放到：

```text
~/.agents/skills/failfirst/
```

在仓库根目录执行：

```bash
mkdir -p ~/.agents/skills/failfirst
cp SKILL.md ~/.agents/skills/failfirst/SKILL.md
```

最终路径应为 `~/.agents/skills/failfirst/SKILL.md`，不要再嵌套一层仓库目录。

然后重启 Codex，或等待 Codex 自动检测 Skill 变化。

## 使用

在 Codex 中显式调用：

```text
$failfirst 我想开始找工作，但一直觉得自己还没准备好。
```

也可以直接说：

```text
使用 FailFirst：

我想做一个付费小工具，但研究半年了，还是不敢向真实用户报价。
```

## 不适用

- 你已经决定行动，只需要完整计划；
- 你只需要计时、提醒或长期习惯管理；
- 你需要心理诊断或治疗；
- 你正面对家暴、自伤、紧急医疗、法律危险或其他高风险不可逆决定。

高风险场景中，安全和专业支持优先，FailFirst 不会用“先失败”推动危险行动。
